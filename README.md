# UPSC Prelims Mock — Set 01

A lightweight, dark-mode UPSC Prelims MCQ practice test (20 questions per set) built in **pure HTML, CSS, and Vanilla JavaScript**. Zero APIs, zero external dependencies, and instant load on both mobile and desktop.

### Live Test
**[Launch UPSC Prelims Mock](https://rahulcodes-ai.github.io/upsc-mock-arena/)**

### Features
- **20 UPSC-Level MCQs:** Covers Polity, Modern & Ancient History, Geography, Economy, Environment, and Science & Tech.
- **Real UPSC Marking Scheme:** Live score calculation with `+2.00` for correct answers and `-0.66` negative marking for incorrect attempts.
- **Instant Explanations:** Immediate right/wrong feedback with concise, exam-relevant explanations after each selection.
- **Question Palette & Summary:** Jump directly to any question (1–20) and view your final score and accuracy breakdown at the end.
- **100% Client-Side:** Runs completely in the browser with zero tracking or backend lag.

### Tech Stack
- Pure HTML5, CSS3, Vanilla JavaScript (Single-file architecture)
- Hosted via **GitHub Pages**
